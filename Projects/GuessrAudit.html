GuessrAudit

Technos utilisées : Reverse engineering JavaScript API

Description

GuessrAudit est une extension de navigateur qui intercepte et analyse le trafic réseau du jeu web OpenGuessr. Grâce à un travail de reverse engineering sur les communications entre le client et l'API, elle permet de contourner les mécaniques du jeu : révélation des coordonnées GPS cachées et modification directe des statistiques du joueur (Expérience, Badges, Pins). Cette solution met en lumière les risques liés au manque de validation stricte côté serveur dans les applications web modernes.

Fonctionnalités

  • Radar en temps réel : Interception des requêtes de métadonnées pour extraire la position GPS exacte et l'afficher sur une carte interactive.Capture de session dynamique : Vol "à la volée" du Token d'authentification (JWT) et de l'ID joueur via la technique du Monkey Patching sur les requêtes fetch et XHR.
  • Exploitation de l'API (Broken Access Control) : Envoi de requêtes HTTP forgées pour injecter de l'XP (exploitation de la limite de validation à 9998/requête) et forcer le déblocage de cosmétiques.
  • Intégration transparente : Injection d'une interface utilisateur (UI) de contrôle directement dans le DOM (la page existante) du jeu.
